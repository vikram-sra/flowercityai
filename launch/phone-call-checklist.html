Before the call

The conversation

If funding comes up

Afterward

Useful objections

“I’m not technical.” “That’s fine. We start with your work, and explain each step.”

“Will I have to buy more?” “No. Each scope stands on its own. We will agree any additional work separately.”

“It costs too much.” “Let’s check whether this task is worth a paid project and start with the smallest useful scope.”
